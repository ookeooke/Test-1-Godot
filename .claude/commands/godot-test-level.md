# Quick Level Test

Launch Godot and run level_01.tscn directly for quick testing:

`"C:\Users\ollil\Downloads\Godot_v4.5.1-stable_win64.exe (1)" --path "c:\Users\ollil\Test-1-Godot" res://scenes/levels/level_01.tscn`

This skips the main menu and loads the level immediately.

After launching:
1. Wait 5 seconds for the game to start
2. Read the most recent 50 lines from the Godot log
3. Report any errors or warnings that occurred during level load
4. If no errors, report "✅ Level launched successfully"

This is useful for rapid iteration when testing level changes.
